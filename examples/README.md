# Examples

The five-slide Portfolio starter and finished example are bundled in **New presentation**. Each creates an independent editable copy covering case study, process, results, gallery and details/credits. The finished fictional library project uses original `portfolio-library.svg`, `portfolio-signs.svg`, `portfolio-workshop.svg` and `portfolio-plan.svg`, licensed with the project under Apache 2.0; it requires no remote assets. See `docs/layout-collections.md` for the compositions and safe layout-change workflow.

Comic starter / finished example add four story compositions and three original `comic-seed-*.svg` illustrations. The fictional seed-sharing story keeps dialogue and captions editable. All included original artwork is Apache 2.0.

Editorial starter / finished example supplies a fictional five-slide Community Notebook with newspaper/blog treatments. It reuses original bundled library diagrams with explicit credits and makes no real participant or measured-outcome claims.

Import `layout-sampler.json` through **Presentations → Open ZIP / JSON** to explore twenty-two layouts, including Media Grid, five Portfolio, four Comic and five Editorial compositions. It contains neutral demonstration copy, no customer material, and no external assets. The JSON includes an empty history to keep it easy to review.

To demonstrate media placement, select its Media slide, choose **Edit media**, and upload `sample-diagram.svg`. Try right/left, below, full-screen, background, and corner inset placements; add a caption and inspect the preview. Export an editable ZIP to include the uploaded media.

For video, use a short recording you own, choose muted autoplay, and test normal duration, wait-for-end, and manual advancement. Recordings are not included in source control.
