## Tables and Code / Commands — issue #104

Positioning and Library polish follow-up #105: newly inserted Tables and Code are free blocks with Move/Resize handles, snapping, precise Arrange dimensions, Layers, lock and removal. Delete restores through Undo; code removal also clears its per-slide command settings, restored together by Undo. Existing layout content stays in place; Inspector Arrange provides Make existing table/code movable actions. Code remains limited to one block per slide; copy it via Library to another slide rather than duplicating it on the same slide. Data containers scroll overflow and keep text readable instead of shrinking it. Library cards have live miniature previews and styled two-column setup controls.

Use the Data & Code Library tab to insert a table (1–30 body rows, 1–12 columns, optional header) or paste a shared code snippet. Inspector Content edits code and optional variants; table cells and existing table controls remain editable. Insertion entry points are removed from the old Inspector panels. One code block per slide is supported; inserting another asks before replacement, with Undo recovery.

Language and environment are optional descriptive labels. Blank language means plain text; no syntax-highlighting engine or execution is added. Use Python/C++/JSON or custom language labels, and Windows/Linux/macOS/npm/pip/Docker or arbitrary environment labels independently. A shared snippet needs no variant name. Add up to twelve distinctly named variants only when content differs. Empty variants are omitted from playback. Choose the initial variant explicitly or enable optional OS preference based on environment labels; switching remains available. Hide the whole code block separately without deleting its content. Existing PowerShell/Bash fields are preserved, with identical values displayed once; conversion to the flexible model retains differing platform texts as named variants. Older editors retain compatibility fallback strings but cannot author the extended variant metadata; keep editable backups.

Manual follow-up: insert a table and edit headers/cells/rows/columns; paste a single shared snippet with no labels; add Python and package-manager variants; change the initial variant, empty one, hide/unhide the block, test optional OS preference and Copy. Test locked slides, Undo, legacy pairs and editable/playback/booth reopening offline. Commands are displayed/copied only. Publication remains disabled pending this new manual review.

Approved scope: consistent block selection/handles/actions, contextual formatting above the canvas, searchable Add panel, Callout/Quote/Metric widgets, one-level grouping and independent reusable presets. Inspector, Layers and canvas share selection and validated transactions. Theme roles follow the destination theme; explicit custom colors remain fixed. Text alignment and object alignment are distinct. Presets include required media, use fresh identities on insertion and survive offline library export/import. Browser-profile storage is local and requires exported backups. Deleting a preset leaves inserted copies intact; recovery must support accidental deletion.

Groups have one level; nested groups are rejected. Locked children prevent group mutations. Group operations use one Undo step. Existing project formats remain readable by encoding ordinary safe AST content and class tokens, without a schema migration. Older editors can render the content but do not provide group/library authoring controls. Widget content remains editable and groups can be ungrouped. Selection and widget-session state are never serialized.

Toolbar overflow must work at laptop widths and browser zoom, preserve text selection/focus, expose mixed values and retain precise Inspector controls. Report text overflow without silently shrinking it. Include original starter components and an optional keyboard-accessible walkthrough.

Acceptance: create a themed card, group it with an image, save/export its preset, import into a clean profile, insert into a differently themed presentation, verify independent editing, fresh IDs/media, Undo, clean-profile editable restore and offline playback. Cover locks, missing/colliding assets, cancelled/invalid imports, library recovery and existing projects. Run npm run check and npm run package plus protected Windows/Linux checks. Manual browser/keyboard/screen-reader/OBS review remains pending until the maintainer tests the beta review build.

Excluded: linked instance updates, timers, interactive widgets, cloud/shared libraries, external services and a full runtime rewrite. Implement only the registry/hooks needed by this scope. Beta publication requires the separate release-process manual gates; do not claim them from CI.
