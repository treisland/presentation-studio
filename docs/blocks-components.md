# 0.6.0 — Blocks, Widgets and Reusable Components beta

Approved scope: consistent block selection/handles/actions, contextual formatting above the canvas, searchable Add panel, Callout/Quote/Metric widgets, one-level grouping and independent reusable presets. Inspector, Layers and canvas share selection and validated transactions. Theme roles follow the destination theme; explicit custom colors remain fixed. Text alignment and object alignment are distinct. Presets include required media, use fresh identities on insertion and survive offline library export/import. Browser-profile storage is local and requires exported backups. Deleting a preset leaves inserted copies intact; recovery must support accidental deletion.

Groups have one level; nested groups are rejected. Locked children prevent group mutations. Group operations use one Undo step. Existing project formats remain readable by encoding ordinary safe AST content and class tokens, without a schema migration. Older editors can render the content but do not provide group/library authoring controls. Widget content remains editable and groups can be ungrouped. Selection and widget-session state are never serialized.

Toolbar overflow must work at laptop widths and browser zoom, preserve text selection/focus, expose mixed values and retain precise Inspector controls. Report text overflow without silently shrinking it. Include original starter components and an optional keyboard-accessible walkthrough.

Acceptance: create a themed card, group it with an image, save/export its preset, import into a clean profile, insert into a differently themed presentation, verify independent editing, fresh IDs/media, Undo, clean-profile editable restore and offline playback. Cover locks, missing/colliding assets, cancelled/invalid imports, library recovery and existing projects. Run npm run check and npm run package plus protected Windows/Linux checks. Manual browser/keyboard/screen-reader/OBS review remains pending until the maintainer tests the beta review build.

Excluded: linked instance updates, timers, interactive widgets, cloud/shared libraries, external services and a full runtime rewrite. Implement only the registry/hooks needed by this scope. Beta publication requires the separate release-process manual gates; do not claim them from CI.

## Beta manual review checklist

1. Extract the beta ZIP and open presentation-studio.html. Open the editor and Add / Library; search/filter and insert Text, Circle, Callout, Quote and Metric. Inspect the original previews and Quick walkthrough. Repeat from presentation-studio-blank.html.
2. Edit widget fields in Inspector Content and directly on the canvas. Enter on a focused block edits its text; Escape/Done ends editing. Verify Move/Resize handles, duplicate/delete, theme styling, custom colors/opacity, font size, bold/italic and text alignment. Open Text format, Appearance, Arrange and More popovers for relevant controls. The toolbar requires no horizontal scrolling; detailed controls remain in the Inspector. Escape closes a popover and returns focus to its trigger.
3. Select several free blocks and floating media using Layers. Group, move a member, resize, align the group, duplicate and ungroup. Internal spacing must survive group alignment. Locked members must prevent mutations; Undo/Redo restores each operation as one step. Nested groups are intentionally rejected.
4. Name and save the selection to Library. Rename/duplicate/delete the preset and restore the last deletion. Insert independent copies and change one; other copies and the saved preset must stay unchanged. Theme-linked styles follow the destination theme; custom hex values stay fixed.
5. Export the library JSON. In a clean browser profile import it, insert the grouped image component and confirm all media loads offline. Export/reopen an editable project ZIP and playback ZIP; preserve IDs for existing slides and fresh identities for inserted copies. Missing or invalid library assets must report an error without replacing the active project.
6. Try cancellation, malformed JSON, unsupported library versions, locked slides/projects, storage unavailable/full and oversized libraries. Storage is local to this browser profile; keep exported library and editable project backups. Libraries allow 40 presets; recent deletion recovery retains ten presets. Grouping/saving supports free blocks and floating media, not structured Media Grids or arbitrary layout roots.
7. Review laptop/desktop sizes, browser zoom, dark/light appearance, keyboard focus, native dialog Escape/Close and screen-reader names/status. Toolbar overflow must not cover the canvas; preview-only/editor controls must stay out of exported content.
8. Open representative legacy projects and check recovery, actual delivery video/OBS if supported, editable restoration in a clean profile and offline playback. Record OS/browser/screen-reader/OBS versions and the tested beta artifact before authorizing publication. These manual checks are pending.
