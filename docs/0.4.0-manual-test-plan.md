# 0.4.0 manual review

Build with `npm run build` and open `dist/presentation-studio.html`. The public version remains 0.3.0 until separate release preparation. Back up a real project as an editable ZIP first.

1. Add a Blank slide. Confirm it is empty and uses the presentation theme. Add Text, Rectangle, Circle, Callout and media.
2. In Style, try theme swatches for text/fill/border and a slide background. Change the presentation theme: linked colors should follow; custom colors should stay fixed. Try custom hex, 0/50/100% opacity, Transparent, Inherit, border widths and contrast feedback. Save/use/delete a named project swatch.
3. Use Layers to select objects; names must not change visible text. Select multiple check boxes, check Mixed values, and apply a preset in one Undo step. Copy/paste appearance. Undo/Redo must retain other content.

   Open the Color picker beside Custom hex, choose a color and check the hex value updates. Type another valid hex and reopen the picker to verify the reverse direction. Change opacity separately; no project/Undo changes should occur until Apply custom. Cancel the native picker and check the project remains unchanged. Apply, Undo and try an incomplete/invalid hex. Verify locked selections disable the picker and custom Apply.
4. Overlap a block and media. Drag Layers rows and use forward/back and Alt+Up/Down; rendered stacking must match frontmost-first order without moving the objects. Hide/show, lock/unlock and inspect a hidden object. Locked objects must resist style, clearing, reordering and indirect edits.
5. Add a Media Grid with images/video. Cell entries remain nested; use cell selection/swap/detach controls. Grid hide/show and ordering should affect its media. Background media remains pinned below content. Detached media can rotate independently.
6. Move blocks and free media at Fit, 50% and 100% zoom. Check edge/center and equal-spacing guides, six-screen-pixel tolerance, Snap toggle and Alt bypass. Hidden/locked objects must not attract snapping. Escape cancels without a history entry; release is one Undo step. Check numeric placement, rotation and keyboard nudges.
7. Clear selected objects and Undo. Cancel Clear slide, then confirm and Undo; slide ID, section and background remain. Repeat with media and verify a complete editable backup retains recovery assets. Locks/read-only mode must prevent clearing.

   Populate a Grid, detach one item, then clear the Grid through Layers. Its remaining nested media must disappear; the detached free item must remain. Undo restores the Grid and all cell assignments together.
8. Export editable and playback ZIPs, extract completely, and reopen offline in a clean profile. Check swatches/styles, borders, opacity, rotation, stacking, Grid/video and hidden objects. Reopen an older project and verify its original content/IDs/media.
9. Review keyboard focus, tab navigation, swatch names/selected indicators and Layers with a screen reader. Test an actual delivery video and OBS if supported. Record OS/browser/screen-reader/OBS versions, build commit, opening method and scaling with pass/fail results.

Report failures before release preparation. CI does not establish manual OBS/screen-reader results or authorize publication.
