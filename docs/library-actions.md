# Library insertion and saved components

Library cards offer an immediate compact Insert action with the component name in
its accessible label. Image/video insertion says Choose media because it opens a
file picker. Right-click, Shift+F10 and ellipsis menus remain optional shortcuts to
the same buttons and transactions.

My components always shows labeled Rename, Duplicate and Delete actions. Rename
opens an inline field with Save name and Cancel; Enter commits, Escape cancels.
Names are limited to 80 characters. Duplicate creates an independent saved preset.
Delete removes the saved component only, leaving placed copies intact. Restore
deleted recovers the most recently deleted saved preset. Focus returns to the
renamed/duplicated component, a remaining card or the Library search field.

Save selection, Import, Export and Restore deleted stay visible. Save selection
explains why it is disabled when no eligible unlocked free objects are selected in
Edit mode. Libraries remain local to this browser profile; export a library JSON
backup for recovery or transfer. No new library schema or service is introduced.

Actual composition thumbnails and category/filter improvements are separate
coordinated issues. Light/dark, touch, narrow layouts and screen-reader acceptance
remain part of the consolidated milestone's manual review.

## Categories and Blocks filters

Blocks, Widgets, My components and Data & Code pair outline icons with visible labels.
Arrow keys/Home/End retain category keyboard navigation. Within Blocks, All/Text/Shapes/Media
filters combine with the existing category-scoped search. Clear search retains the selected
filter and returns focus to the search field. Empty results suggest clearing search or changing
category/filter. Media retains its upload picker; this does not add a stock icon catalog or
cross-category search. Decorative line/arrow/button/step previews show their existing kinds.

Duplicating a saved component focuses the new copy’s Rename action, so keyboard
renaming applies to that copy. Existing saved and placed copies remain independent.
