# 0.3.0 local test plan

Use the current local build: run `npm run build`, then open `dist/presentation-studio.html`. This is the development build for 0.3.0 features; the public version remains 0.2.0 until a separate release preparation PR. Start with a disposable presentation or an editable ZIP backup of your real project.

## Panel polish (5 minutes)

Collapse Slides left and Inspector right using the edge chevrons, then reveal each from its labeled rail. Search/Add slide and the selection header should remain fixed while their lists/fields scroll. Try Content/Arrange/Style tabs with mouse and arrows/Home/End, change selection and confirm the active section is retained. Select a circle and use the header's Duplicate/Delete block, Undo and locks. Select text, switch to Style and format it. Check precise removal labels for media/grid cells and keyboard access to each thumbnail's secondary actions. Panel view changes must not create Undo entries or change saved project data.

For Grid selection, populate two cells, select the first on the canvas, then select the second media object in the Inspector list. The header, selected-cell field and removal confirmation must identify the second cell; remove it and verify the first remains unchanged, then Undo.

## Content blocks (5 minutes)

1. Open the editor and use **Add block** to add Text, Rectangle, Circle and Callout. Check that Text has no opaque card background, shapes use the accent fill with readable text, and the Callout has an accent border.
2. Move and resize a block at Fit and 50%/100% zoom. Drag near the center/edges to check snapping; Alt bypasses it. Escape during a drag must restore the original placement.
3. Tab to Move/Resize, use arrows and Shift+arrows, then change position/size, alignment and layer in the inspector. Duplicate, remove, Undo and Redo. Existing text/media must remain intact.

## Media Focus (3 minutes)

1. In editing mode, clicking media selects it. In Preview and Present, clicking an image/video viewport opens Media Focus. The old visible Expand button is gone.
2. Tab to **Open media focus: [name]**. It appears on keyboard focus; Enter and Space open it. Escape returns focus and restores the prior play/pause state. Repeat with an image and video, including paused video and native video controls.
3. Check image zoom/Fit, captions and reduced motion. Clicking native video controls should operate the video without unexpectedly opening Focus.

## Media Grid (10 minutes)

1. **Add slide → Media Grid**. In its inspector select a cell, then Add media; also drop a file directly on an empty cell. Mix at least two images and one real delivery video. Each addition must preserve all other cells.
2. Try 2 × 2, 3 × 1, 3 × 3, custom rows/columns and spacing. Shrink a populated grid: Cancel must keep it unchanged; confirming must retain overflow media as free objects. Undo returns the grid.
3. Replace a populated cell: the dialog must name the old file and preview the new one. Cancel preserves it; confirm changes only that cell. Try Fit/Fill, crop X/Y, captions and alternative text.
4. Move/swap cells, remove one cell's media and Undo, then detach an item for free positioning. Remaining media and their playback settings must survive.
5. Drag row/column dividers at different zoom levels. Escape cancels without an undo entry; releasing commits one undo step. Tab to a divider and use arrows/Shift+arrows. Check selection/names and inspector file upload using keyboard only.
6. Lock a media object and the slide in turn. Protected content must resist replacement, removal, swaps, divider resizing and undo that would change it. Unlock to continue.

## Save and reopen (5 minutes)

Export both an editable ZIP and playback ZIP. Extract each to a new folder and open `index.html` offline in a clean browser profile. Check every image/video, crop, caption, grid placement and Media Focus. Reopen the editable version and confirm the grid can still be edited. Also open an older project and verify its original slide IDs/content and media remain intact.

Report pass/fail, the build commit, Windows/browser versions, display scaling and any failing step. Screen-reader review and actual OBS/recorded delivery-video evidence must be recorded separately; automated tests do not establish those manual results.
