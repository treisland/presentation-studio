Record artifact SHA256, source SHA, OS/browser versions, display arrangement,
reviewer, date and findings for each run.

- [ ] First-time viewer: identify Previous/Play/Next, Fullscreen and More. Verify
  labels before hover, light/dark/forced colors, visible focus and touch/narrow
  layouts. Controls remain reachable without overlapping primary navigation.
- [ ] The original animated slide-time line is visible by default. Show/hide it
  independently of numeric seconds and deck position. Play/pause/next/reset,
  single-slide decks, authored defaults, session overrides and legacy fallback
  preserve the intended state without changing playback.
- [ ] Auto-hide and Always visible obey pointer/touch/keyboard activity, open
  menus and focused controls, with Kiosk both on and off. Check reduced motion,
  manual/timed playback and a presentation without named sections.
- [ ] Allow a blocked popup explicitly, move audience to the real display and
  share **only the audience window**. Identify LIVE/private preview and read notes
  privately. Search/List/Grid/Return preview never commit an audience change.
- [ ] Browse away from LIVE, use live Previous/Next, explicitly Follow live, and
  test native search/select keyboard behavior. Test hidden/single/large decks and
  cancel/close/reopen with meaningful focus restoration.
- [ ] Begin detour once, present several answers and Return preview to live.
  Resume explicitly restores the original anchor. Test an unavailable saved
  target and a slide shared by a custom loop and another section; reopen must
  preserve the audience's current navigation order.
- [ ] Blackout retains the live slide and pauses media; restore respects prior
  play/pause. Reopen preserves blackout but starts paused. End is a separate action
  that closes outputs. Confirm previews are silent during actual video/audio.
- [ ] Screen-reader review records Windows/Chrome/NVDA (or actual alternatives)
  and findings: names, markers, status changes, dialogs, input behavior and focus.
- [ ] Actual delivery media, fullscreen/autoplay permissions, dual display/window
