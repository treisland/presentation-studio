## Text types

Select heading/paragraph text, then use Inspector → Content → Text style (Heading 1–3 or Paragraph). Check plain and formatted text, links, a partial/backward selection, repeated conversion, keyboard focus and one-step Undo. Existing custom sizes and collection styling stay applied; review overflow when a heading is larger. Convert a slide title to Paragraph, then edit the slide-title field and inline text; the right title must stay synchronized. Change body text to a heading without changing the slide title.

Try locked project/slide/layer content and unsupported table cells, lists, commands or containers. These must not convert. There is no div/group option. Reopen editable/playback exports offline and check types, formatting, media and identities. Review announcements with your screen reader and record environment versions.

## New presentation

Open New presentation: only Blank and Import are direct choices, beside Start from an example. The gallery has six starting points: Portfolio, Comic, Editorial, Newsletter, Flyer and Studio. Check filters, full previews, captions and text descriptions. Studio has a finished demo, not a separate starter; Newsletter/Flyer have lightweight starters only. Check the Studio demo from the blank build as well.

Choose an example and continue through naming, branding, preview and appearance before creating. Confirm custom settings and reset baseline carry through. Try Use defaults. Back to the starting page should show the selected example without duplicated radios; choose Blank to clear it. Import still opens the project file picker.

Close/Escape from gallery or setup, cancel save-before-switch, and switch between existing drafts. No cancelled action should replace the active project. Create two separate copies, replace artwork, reset your copy, and check the original library stays unchanged. Verify editable/playback exports and clean-profile offline reopening. Check keyboard traversal, focus return, laptop/desktop and light/dark modes.
