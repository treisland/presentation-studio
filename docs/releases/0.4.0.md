# v0.4.0 — Styling and precision

Stable 0.4.0 promotes the published, maintainer-tested candidate without runtime, dependency or project-format changes. The maintainer confirmed manual review passed and granted sign-off after candidate publication.

## Included improvements

- Theme-linked/custom text, fill, border and slide-background colors; separate opacity; synchronized native color picker/hex input; named project swatches; contrast estimates; presets and copy/paste appearance.
- Blank slide template and lock-aware Clear selected/confirmed Clear slide, retaining identities, backgrounds and atomic Undo/recovery.
- Layers selection, naming, hide/lock, pointer/keyboard order, nested Grid cells and pinned backgrounds; batch appearance/Mixed values and validated independent rotation. Native Arrange controls share the actual stack.
- Object/slide alignment and equal-spacing snapping with transient guides, screen-pixel tolerance, toggle and Alt bypass.
- Grid removal clears referenced nested media while preserving detached objects and recovery. Repeated layer keys are rejected atomically before unrelated content can be removed.

Original projects remain supported through additive optional design metadata. No schema migration, external service or major dependency is introduced. Use a current build to retain new design features when re-exporting. See [the feature guide](../styling-and-precision.md).

## Support and evidence

Protected automated coverage uses Chromium on Windows/Linux. The maintainer reported the supplied manual checklist passed and subsequently confirmed review/sign-off of the published RC, including the late removal fixes. See [the evidence record](0.4.0-evidence.md).

Exact manual OS/browser/screen-reader/OBS versions, capture/opening method and scaling remain unspecified. Automated tests do not independently prove OBS/screen-reader results; no broad browser/codec guarantee, OBS Browser Source support or accessibility certification is claimed. Detailed follow-ups #7/#9 remain open.

Styles apply to objects rather than partial character ranges; inline Bold/Italic remains available. Grid cells use their cell tools and must be detached for independent rotation/order. Contrast estimates assume solid colors; opacity and images can alter the actual result. Gradients, shadows, grouping, layout collections, AI and MCP remain separate scopes.

## Backups and recovery

Extract complete packages before opening HTML. Keep a full editable ZIP with all media before clearing browser data, changing profiles or moving computers. Browser-local drafts are profile-specific; playback exports are not editable backups.

Verify backup ZIP checks archive/data integrity, not codec support. Prove restoration by importing into a clean profile and checking media offline. Use Undo/checkpoints/trash for recovery, retaining original assets and backups before reset/restore.
