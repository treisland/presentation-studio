# Presentation Studio 0.13.0-beta.1

This beta adds interactive navigation and reusable media frames.

- Insert filled/outline buttons, text links and navigation arrows. Assign stable slide destinations, next/previous or HTTP(S) resources opening in an isolated new tab.
- Keep action controls expanded near the top of Content. Complete choices save immediately; URL entry shows a pending indicator until Enter or blur.
- Insert rectangle/rounded/circle/oval image/video frames. Adjust zoom, crop, corner radius, border padding and shadow with shared sliders and precise fields. Each completed gesture is one Undo step, without Apply frame.
- Keep fill, outline and shadow on the mask contour, preserve media during placement changes, and retain frame/action settings in reusable presets and offline exports.
- Fit all five drop-placement choices with long filenames and keep media controls in one scrollable Inspector.

Existing native v1/v2 imports and the native-v3 background-effects guard remain supported. Original media, IDs, recovery/history and editable/playback/booth workflows remain covered. This beta introduces no service, dependency or native format-generation change. Older editors do not understand the new optional action/frame metadata; retain original editable ZIP backups and use this build for these features.

The maintainer confirmed all UI tests and the explicitly listed manual release gates passed on latest runtime `1361138`, and granted beta sign-off. Protected PR/exact-main/tag and artifact checks remain mandatory. See [validation and authorization](0.13.0-beta.1-validation.md), [feature guide](../interactive-elements.md) and [manual checklist](../0.13.0-manual-test-plan.md).

External resources require connectivity. Slide links outside a playback loop report their limitation. Arbitrary/gradient masks, conditional actions, scripting, direct AI providers and new services remain outside this release. Stable channels remain unchanged; npm publication is not included.
