# v0.2.0-alpha.2 — Backup verification, media coverage and keyboard access

This alpha packages the improvements merged since alpha.1:

- **Verify backup ZIP:** choose Edit → Project → Export → Verify backup ZIP to inspect an editable project without importing it or changing your active project, drafts or backup freshness. Checks cover project structure, active/recovery assets, CRC integrity, original member paths/counts/sizes and duplicate entries. Cancellation is supported; original archive limits and supported ZIP variants are documented in the quick start.
- **Media regression coverage:** original silent H.264 MP4 and VP8 WebM fixtures cover playback, focus identity/position/pause continuity, exact exported bytes, editable/playback ZIP reopening and clean-profile import. Matching Chromium and installed Chrome 157.0.8103.38 passed the documented Windows runs; this does not establish support for every codec or actual delivery file.
- **Keyboard accessibility:** movement controls and tab panels have descriptive names. Readiness and backup dialogs cycle Tab appropriately. Automated authoring, movement/undo, export, verification, slide creation and clean-profile import workflows are covered.

Verification checks archive integrity and project data, not actual rendering, media decoding or authenticity. It never executes the archived HTML. Test a clean-profile restore and your actual presentation before clearing an original browser profile. Keep complete editable ZIP backups.

## Validation and remaining gates

The merged changes passed Windows/Linux protected CI. Local full validation includes 20 build/delivery tests and 55 browser tests; installed-Chrome keyboard and fixture runs are documented separately. Release preparation and the tagged artifact workflow rerun required checks.

This remains an alpha. OBS and actual delivery-video evidence (#7), NVDA announcements and remaining manual accessibility tasks (#9) are pending. Manual gates are not marked passed; beta/RC/stable require the evidence tracked in #30. There is no project schema migration, and third-party licenses are unchanged.
