# v0.4.0-rc.1 — Styling and precision

This candidate freezes the maintainer-reviewed 0.4.0 scope. Test the published candidate artifacts before stable sign-off. Publication is governed by [the evidence record](0.4.0-evidence.md) and protected release checks.

## Included improvements

- Theme-linked/custom text, fill, border and slide-background colors; separate opacity; synchronized native picker/hex entry; named project swatches; contrast estimates and reusable appearance presets/copy-paste.
- Blank slide template and lock-aware Clear selected/confirmed Clear slide with stable identities, retained backgrounds and one-step Undo/recovery.
- Layers selection, naming, hide/lock, pointer/keyboard ordering, nested Grid cells and pinned backgrounds; batch appearance and Mixed values. Rotation and native Arrange controls share validated state.
- Object/slide alignment and equal-spacing snapping with transient guides, screen-pixel tolerance, toggle and Alt bypass.
- Removal fixes preserve detached/unrelated media when clearing Grids and reject repeated layer IDs atomically.

Original projects remain supported through additive optional design metadata; no schema migration, new external service or major dependency is introduced. Use a current build when re-exporting new styling metadata. Review [the feature guide](../styling-and-precision.md) and [manual checklist](../0.4.0-manual-test-plan.md).

## Support and limitations

Protected automated coverage uses Chromium on Windows/Linux. The maintainer reported the supplied manual review passed; exact OS/browser/screen-reader/OBS versions, capture/opening method and display settings remain unspecified. Automated tests are not independent OBS or screen-reader evidence. Other browsers/codecs and OBS Browser Source are not claimed supported without separate evidence; no accessibility certification is claimed. Detailed follow-ups #7/#9 remain open.

Styles apply to content objects rather than partial character ranges; inline Bold/Italic remains available. Grid media uses cell tools and must be detached for independent rotation/reordering. Contrast is an estimate for solid colors; opacity and images can alter it. Gradients, shadows, grouping, layout collections, AI and MCP are outside this candidate.

## Backups and recovery

Extract complete packages before opening HTML. Keep a full editable ZIP with all media before clearing browser data or moving profiles/computers. Local drafts are profile-specific; playback packages are not editable backups. Verify backup ZIP checks archive/data integrity, not codec support: prove restoration by importing into a clean profile and checking media offline. Use Undo/checkpoints/trash for recovery, retaining original assets and backups before reset/restore.
