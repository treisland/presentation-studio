# Presentation Studio 0.11.0-beta.1

Maintainer-approved beta for Tables and Library manipulation. This prerelease preserves native project v2, existing legacy v1, portable authoring v1 and component library v1. Stable 0.7.0 and previous release tags remain unchanged.

- Select a table cell and insert rows above/below or columns left/right; delete the selected row/column. Headerless tables retain their data. Structural edits preserve unaffected rich text, links and attributes, with locked-table protection and Undo.
- Use Inspector Style for Plain, Header, Banded and Grid presets; semantic header toggles; header/body theme or custom colors and alignment; alternating rows; borders; and cell spacing. Existing tables keep their appearance until explicitly styled. Saved Library copies and editable, playback and independent booth exports retain the new styles.
- Shift+click or drag from empty canvas to select multiple items. Marquee selection includes fully enclosed eligible objects and complete groups, excluding hidden/locked items. Text selection and Space+drag panning remain available.
- Group/Ungroup directly from the selection actions or Ctrl/Cmd+G and Ctrl/Cmd+Shift+G. Shared move/resize handles, member editing, Escape return and named Layers group headers make existing one-level groups easier to use. Ungrouping preserves positions, styles, names and stacking and keeps released members selected.
- Keep contextual actions in a floating dock that does not shift the canvas. Table and group actions remain reachable together when editing a grouped table; changing to another object clears stale group-editing context. Concurrent edit batches are rejected during selection gestures.

## Use and recovery

Download and extract the full package, then open `presentation-studio.html` or its blank entry point. Use **Add / Library → Data & Code** to insert a table. See [Tables and Library manipulation](../tables-and-grouping.md) for editing, keyboard controls and compatibility details.

Keep complete editable ZIP backups. Browser recovery is separate from portable backups. Saved components insert independent copies with fresh identities. Earlier editors retain ordinary content but may not reproduce new table styling or offer these controls; use current exports for matching playback. No format migration or new dependency is introduced.

After verified downstream promotion, use [beta.pres-studio.com](https://beta.pres-studio.com/) or `ghcr.io/treisland/presentation-studio:0.11.0-beta.1`. Canonical publication and downstream website/registry promotion are independently gated. Docker remains a static app server; presentations stay in the browser or downloaded files. See [deployment](../deployment.md).

## Acceptance and limits

The maintainer pre-approved beta sign-off conditional on passing CI, then separately confirmed all listed manual release checks passed on 2026-11-11 (America/Denver). Automated and maintainer-reported evidence are distinguished in the [validation record](0.11.0-beta.1-validation.md). Exact manual environment versions and recording URLs were not supplied; none are invented.

Nested groups, spreadsheet formulas, merged-cell authoring, CSV import, status badges and marketplaces remain outside scope. Imported merged/irregular tables retain content but cannot use rectangular structure edits. Table insertion is limited to 30 data rows and 12 columns; removing a header that would exceed the data-row limit requires removing a data row first. Very large tables can overflow; resize the frame or reduce spacing. Linux AMD64 remains the certified image baseline. Native folder access, server storage, accounts, npm publication and stable promotion are not included.
