# v0.2.0-alpha.1 — Presentation readiness

The first 0.2 alpha adds **Check readiness** to the editor. Review missing media/logo/recovery assets and slide overflow as blockers, plus advisories for hidden slides/sections, selected-loop exclusions, portable backup freshness and video capability. Findings navigate to the relevant slide or settings without changing project data or undo history. Keyboard navigation retains destination focus; dismissal returns to Check readiness.

Delivery automation now discovers drafts reliably and verifies an immutable tagged commit even if main advances. No project schema migration is introduced.

Validation includes clean and deliberately broken fixtures, read-only project comparisons, keyboard focus, existing legacy imports, recovery and export/reopen regressions. Windows/Linux matching Playwright Chromium checks gate publication.

This is an alpha for feedback, not completed 0.2 functionality. Real-video compatibility expansion (#7), isolated backup verification (#8) and the screen-reader audit (#9) remain pending. Capability hints do not guarantee codec decoding, autoplay, installed Chrome or OBS playback. Export and keep editable ZIP backups.

Downloads: `presentation-studio.html`, `presentation-studio-blank.html`, `presentation-studio-v0.2.0-alpha.1.zip`, and `studio-demo-editable.zip`. Unzip complete packages before opening.
