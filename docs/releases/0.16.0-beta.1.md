# Presentation Studio 0.16.0-beta.1

This beta brings together the v0.16.0 presentation, Library and custom-background
milestone, plus the locally reviewed documentation/marketing companion.

- Switch between Classic, Modern and Hidden presentation bars. The optional
  animated slide-time line remains independent of deck-position progress.
- Use the full-window Presenter workspace with compact title/thumbnail List/Grid
  browsing, private local search, readable Live/Preview notes and explicit
  audience controls. Double-click presents a slide; private Previous/Next browsing
  remains separate from audience navigation.
- Use true audience blackout or an optional static built-in/custom holding
  screen. Restore retains the live slide, timer and Q&A resume point.
- Apply presentation, single-slide, section or selected-slide backgrounds with
  explicit overrides, image Fill/Fit and focal point, readability overlays,
  coordinated looks, reset and Undo. Single-slide Background controls are available
  directly in the Inspector.
- Browse clearer Library categories and permanent Insert/management actions,
  with static previews of saved compositions.
- Review the 11-page documentation/marketing companion locally. Public companion
  hosting and publication remain deferred and are not part of this app release.

Window capture is the recommended presentation-capture path. OBS-specific
sign-off is no longer a release gate; future Browser Source deprecation remains
separate from this release and unverified source-specific support is not claimed.

## Compatibility and recovery

Existing native v1/v2/v3 and portable-authoring v1 inputs remain importable.
Custom backgrounds use the separately approved guarded native v4 and authoring
v2 formats; untouched older files retain their generation. Older editors reject
new formats rather than discard backgrounds. Preserve original editable ZIP
backups and test complete playback ZIPs on the delivery machine. See
[import compatibility](../import-compatibility.md).

## Known limitation

Cancelling holding settings after a saved holding slide was deleted or hidden can
lose the usable built-in fallback. Explicitly select Built-in design before Show
holding screen. The maintainer accepted [#241](https://github.com/treisland/presentation-studio/issues/241)
for a later patch; it is not fixed here. See [known issues](../known-issues.md).

## Validation and publication

The maintainer reported all app manual checks passed and authorized this beta,
followed by the official release if beta CI passes. See the
[validation and authorization record](0.16.0-beta.1-validation.md).
Protected source/preparation/main checks, resolved review conversations, immutable
tag workflow and four complete digested artifacts remain required. This beta plan
does not itself authorize a stable tag or companion deployment. Stable promotion
uses a separate release-preparation PR after the beta succeeds.
