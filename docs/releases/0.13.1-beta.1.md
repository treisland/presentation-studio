# Presentation Studio 0.13.1-beta.1

This beta patch fixes delayed typing in Library elements on the canvas and in the Inspector.

Status updates previously built an export pack, which flushed the pending edit, refreshed editor UI and copied the full project/Undo history on every keystroke. Status now reads committed content without creating a pack and marks pending text as needing a new portable backup. Typing stays grouped for Undo; leaving a completed text field commits it before a following action. Explicit save/export still commits the latest text.

Regression coverage checks both typing paths with an existing ZIP backup, one-step Undo/Redo, completed-field actions and clean offline editable ZIP restoration. The original source produced 76 full-pack serializations for 19 typed characters in each path; the corrected paths produce none during the typing burst.

This patch changes no native format, project IDs, assets, dependencies, media rendering or deployment service. Existing navigation/mask features and limitations remain as described in [0.13.0-beta.1](0.13.0-beta.1.md). Keep original editable ZIP backups when moving between editor versions. See [validation and authorization](0.13.1-beta.1-validation.md).

Distribution targets beta Pages and versioned/beta GHCR only. Stable remains unchanged. External links require connectivity; downloaded authoring/playback remain offline-capable.
