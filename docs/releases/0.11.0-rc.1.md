# Presentation Studio 0.11.0-rc.1

Maintainer-approved release candidate for the accepted 0.11.0-beta.2 build. This progression changes version metadata and documentation only; it adds no runtime behavior, dependencies, storage or project-format changes. Beta.2 and previous releases remain immutable. Stable promotion is not authorized by this RC.

The candidate includes contextual table structure/style controls, direct canvas selection/grouping, template-table action focus retention, panel-to-inline cell edit preservation, and deferred navigator snapshots that refresh completed appearance/visibility/media changes. See [beta.2 notes](0.11.0-beta.2.md), [table/group usage](../tables-and-grouping.md) and [RC validation](0.11.0-rc.1-validation.md).

Keep complete editable ZIP backups; browser recovery is separate from portable backups. Supported formats remain native project v2, existing legacy v1, portable authoring v1 and component library v1. Prior editors may retain content without reproducing new table styling; use current exports for matching playback.

Known limits remain unchanged: one-level groups only; imported irregular/merged tables retain content but cannot use rectangular structure edits; large tables may overflow; nested groups, formulas, CSV import, native folder compatibility certification, accounts and server storage are outside this release. Detailed accessibility/media environment documentation remains tracked in existing follow-ups; exact manual environment versions and recording links were not supplied and are not invented.

After verified RC distribution, use [beta.pres-studio.com](https://beta.pres-studio.com/) or `ghcr.io/treisland/presentation-studio:0.11.0-rc.1` (the `rc` alias). The website remains on the prerelease origin; the Docker `beta` alias and stable/latest channels are not advanced by RC promotion. Canonical publication and Docker/website deployment retain independent integrity checks. No npm publication is included.
