# Presentation Studio 0.18.0-alpha.1 — local review

This local alpha starts from published `v0.17.0-beta.2` (commit `c6f8ccb`)
and implements milestone #26's Windows-inspired horizontal editor menu bar.
File, Edit, View, Insert, Format, Arrange, Slide and Help organize existing
commands. Present/Export stay prominent and detailed values stay in the
selection-driven Inspector. The conversation POC guides hierarchy and behavior.

See [menu behavior and local testing](../editor-menu.md) and the
[validation record](0.18.0-alpha.1-validation.md).

Existing saved formats, IDs, original media/audio assets, recovery and offline
exports retain their contracts. Known issue #241 remains outside this milestone.
No dependency or external service is added.

The maintainer requested local testing first and no PR. This is not a published
alpha or beta. `release-plan.json` has `publish: false` and manual acceptance is
pending. The latest beta and stable deployments remain separate released builds.
