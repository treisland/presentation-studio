# Presentation Studio 0.19.0

This production release promotes the maintainer-accepted 0.19 runtime without
further feature changes. It includes the verified beta/RC features:

- Native editable column, horizontal bar, line and donut charts, staged data/style
  editing, spreadsheet paste, named color pickers and targeted category/series
  controls. Chart settings close correctly after reopening editable exports;
  small nonzero values retain meaningful precision.
- Native portable AI chart authoring with both schemas, examples and refreshed
  agent/Library capability instructions. Download a fresh instruction pack.
- The accepted menu bar and start screen, recent browser projects, recovery-safe
  creation/opening and the existing portable audio/background workflows.

See [Charts & Graphs](../charts-and-graphs.md), [start screen](../start-screen.md),
[editor menus](../editor-menu.md) and [release validation](0.19.0-validation.md).

## Support and known limitations

Known [holding-screen issue #241](../known-issues.md) remains accepted for a patch:
after a saved holding slide is hidden/deleted, explicitly select Built-in design
before Show holding screen. No fix is claimed; true blackout remains available.
Manual browser acceptance is maintainer-reported on the established Windows
Chrome/Firefox/Edge baseline. Other platforms and codecs are not newly certified
by automated Chromium checks. Accessibility evidence retains its documented
scope. Ordinary window capture is recommended; unverified OBS Browser Source
support is not claimed. No dependency or external service is added.

## Compatibility and recovery

Project IDs, guarded native formats and existing recovery/import contracts remain
unchanged. See [import compatibility](../import-compatibility.md). Keep original
editable ZIP backups; browser recovery is not a backup. Moving between beta and
production origins requires editable ZIP export/import. An old standalone HTML
export keeps its embedded runtime: import its editable ZIP into this version and
export again to receive the fixes. Extract complete playback ZIPs and test actual
media on the delivery machine. See [portable recovery](../local-workspaces.md).

This release authorizes the production app at pres-studio.com through the
existing Pages workflow. The separately approved RC refreshes beta.pres-studio.com.
No Docker aliases, DNS changes or companion-site deployment are included.
