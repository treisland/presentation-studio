# 0.11.0-beta.2 — Authoring stability fixes

Existing template tables now retain their selected cell when focus moves into row/column actions or the table Inspector. Previously, opening the action dropdown could dismiss the controls before an action could be chosen. Row/column insertion and deletion, keyboard actions and Undo/Redo work without converting the table into a free block. Selecting another object or slide still changes the editing context normally.

This is a focused update to 0.11.0-beta.1, retaining its table styles, grouping workflows and compatibility scope. No project-format, dependency or storage changes are introduced. Continue keeping editable ZIP backups; browser recovery is separate from portable backups. See [table usage](../tables-and-grouping.md), [beta.1 notes](0.11.0-beta.1.md) and the [validation record](0.11.0-beta.2-validation.md).

Slide navigator thumbnails and titles now stay stable while typing in the canvas or Inspector. They refresh when editing finishes, another item or slide is selected, or an action completes. The canvas and browser recovery continue updating normally. Existing cards retain keyboard focus and scroll position during ordinary edits, and their titles reserve two lines to avoid moving neighboring cards. These snapshots are temporary view state, excluded from projects and exports.

The maintainer approved this beta update conditional on passing tests and subsequently requested the thumbnail fix as an update to the beta. Prior manual baseline results and this update authorization are recorded separately from automated verification. Published beta.1 remains immutable. Template grouping convenience remains a separate reported follow-up and is not claimed fixed here.

After verified distribution, use [beta.pres-studio.com](https://beta.pres-studio.com/) or `ghcr.io/treisland/presentation-studio:0.11.0-beta.2`. Canonical release publication, beta website and Docker promotion retain their independent checks. Stable promotion and npm publication are outside scope.
