# Presentation Studio 0.11.0

Maintainer-approved stable release of the tested 0.11.0-rc.1 application. This promotion changes version metadata and documentation only. It includes the accepted canvas-first editor, contextual Content/Arrange/Style tools, Library/components, table structure/style editing, direct selection/grouping, panel-cell data preservation, stable navigator snapshots, offline export/reopen and verified static Docker/Pages delivery. See [RC notes](0.11.0-rc.1.md), [table/group usage](../tables-and-grouping.md) and [production evidence](0.11.0-validation.md).

## Production and portable use

After verified deployment, open [pres-studio.com](https://pres-studio.com/) over HTTPS. The beta website remains a separate prerelease origin. Production is served by GitHub Pages from the same verified canonical HTML bytes as the release downloads. Docker users can pin `ghcr.io/treisland/presentation-studio:0.11.0` or the recorded image digest; `stable` and `latest` aliases advance only through explicit verified promotion. npm publication is not included.

For offline use, extract the release package and open `presentation-studio.html` or the blank entry point. Native editable project v2, existing legacy v1, portable authoring v1 and component library v1 remain supported. No project-format migration or new dependency is introduced. Previous editors may retain content without reproducing new table styles; current exports provide matching playback.

## Recovery and limits

Keep complete editable ZIP backups before changing hosting origin or app version. Beta and production browser storage are separate: export an editable ZIP from beta and import it into production; browser recovery does not transfer automatically. Downloaded editable backups remain independent of browser drafts. Hosting/containers do not store presentations server-side, and changing the served app does not restore or migrate browser storage.

Known limits remain unchanged from the accepted RC: one-level groups, no nested groups or spreadsheet formulas; irregular/merged imported tables retain content but cannot use rectangular structural edits; large tables may overflow; native folder compatibility certification, accounts and server storage remain outside scope. Detailed accessibility/media environment documentation remains in existing follow-ups. The maintainer approved production after RC testing; no exact manual OS/browser/OBS versions or recording links were supplied, and none are inferred from CI. Background-effects planning and other roadmap candidates are excluded.

Canonical publication, production website and Docker delivery are independent gates. A partial distribution failure is reported explicitly; immutable releases/tags are preserved. Prefer a fix-forward release for defects. Any rollback requires compatibility review and editable backups because replacing HTML does not revert browser recovery data. See [deployment and recovery](../deployment.md).
