## Automated and visual checks

Final local Windows validation completed on 2026-11-14 (America/Denver):

- `npm run check`: PASS, 496 tests, zero failures/skips. The complete run includes
  build/reproducibility, unit/distribution, browser, components, manipulation,
  Inspector/menu, viewer/Presenter and audio suites. Local log:
  `test-results/menu-alpha-check.log`.
- `npm run package`: PASS, producing
  `release/presentation-studio-v0.18.0-alpha.1.zip` with both HTML entry points,
  original fixtures and the offline menu guide. Local log:
  `test-results/menu-alpha-package.log`.
- `git diff --check`: PASS. Git reports only checkout line-ending conversion warnings.
- Six new menu workflows cover destinations/audio/background, keyboard/submenus/
  focus, pending edits/Undo/stale targets, locks/mixed selections, editable ZIP
  export and responsive light/dark rendering. Existing regression coverage now
  follows the retained shared actions and moved Undo/Redo locations.
- Desktop light/dark, laptop dark and 390px light screenshots were generated and
  visually inspected under ignored `test-results/menu-review/`. Menus remain
  within the viewport; title actions wrap; canvas grips do not overlay menus.
  These are authentic local development captures, not public companion assets.

Validation found and corrected active text sessions retaining stale canvas
content after toolbar Undo, stale disabled-Undo tooltips covering Slides, and
context-menu Back restoring a taller parent without reclamping its position.
Regression expectations for font restoration and interaction guards were retained.
The covered original media is selected through its existing Layers cell entry.

This is local Windows/Chromium evidence. Linux CI and independent manual gates
have not been performed for this uncommitted alpha. No saved-format generation,
dependency or external service was added. The POC guided hierarchy and behavior;
its incidental artwork and shortcut labels were not copied as product claims.
