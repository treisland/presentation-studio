# Presentation Studio 0.20.0

Production release of the maintainer-accepted media authoring and canvas reliability work, preserving the beta/RC runtime unchanged.

## Authoring improvements

- Record and review local slide narration, preserve incomplete takes for download, and choose explicit advancement defaults/overrides.
- Manage original media through Project media, including measured audio previews, reviewed replacement/repair, guarded deletion and recovery retention.
- Select overlapping canvas objects through named choices with preview outlines; keep Layers selection and Inspector context synchronized.
- Finish move/resize/crop/endpoint gestures with pointer ownership, final-coordinate handling, cancellation and atomic Undo. Arrow endpoints stay reachable on their actual geometry.
- Align explicitly to the slide or selection bounds. Space independent objects/groups evenly while retaining group spacing and specialized text/table/chart/media editing.

## Known limits and recovery

The aspirational 50 ms release target is not met. Instrumented simple fixtures measured about 80–120 ms and dense fixtures 240–724 ms under local validation load; dense presentations can still feel delayed. These are observations, not an SLA. Cross-browser/device/codec and assistive-technology support remain bounded by the documented evidence; no expanded certification is claimed.

Preserve a complete editable ZIP backup before upgrading or moving browser origins. Existing IDs, original media, recovery, legacy imports and offline editable/playback/booth reopening retain their contracts. Current native v6 media-bearing projects need a compatible current editor; older editors may reject newer formats. Playback exports are delivery copies, not editable backups. Stable and beta origins keep independent browser storage.

See [release validation](0.20.0-validation.md), [canvas measurements](../canvas-reliability.md), [media authoring](../media-authoring.md) and [import compatibility](../import-compatibility.md).

Canonical publication and production Pages use exact validated immutable release bytes. Screenshot provenance retains its actual labeled version.
