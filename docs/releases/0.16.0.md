# Presentation Studio 0.16.0

This official release promotes the verified 0.16.0-beta.1 runtime without further
feature changes, under the maintainer's explicit authorization after beta CI passed.

- Switchable Classic, Modern and Hidden presentation bars, with optional animated
  slide-time line and independent deck-position progress.
- Full-window private Presenter workspace, compact title/thumbnail List/Grid,
  offline title/text/notes search, readable Live/Preview notes and text sizing,
  deliberate audience controls, double-click-to-present and Q&A detours.
- True audience blackout and optional static built-in/custom holding screens,
  with explicit Restore retaining live slide, timer and Q&A state.
- Custom Theme/Solid/Gradient/Image backgrounds, exact single-slide Inspector
  controls, presentation/section/selected-slide scopes, focal Fill/Fit, readability
  overlays, coordinated looks, override preservation, reset and Undo.
- Clear Library categories, permanent Insert/management actions and static saved
  composition previews.
- Locally built documentation/marketing companion and canonical user guides.
  Public companion hosting and launch remain deferred.

## Known issues and support scope

The maintainer accepted [#241](https://github.com/treisland/presentation-studio/issues/241)
for a later patch: Cancel/Escape in holding settings can restore an unavailable
saved slide choice after that slide was hidden/deleted. Explicitly select Built-in
design before Show holding screen. True blackout remains available; no fix is
claimed. See [known issues](../known-issues.md).

Manual browser acceptance was reported on Windows 11 Pro build 26300 with Chrome,
Firefox and Edge; exact reported versions and evidence boundaries are in the
[validation record](0.16.0-validation.md). Other environments are not newly certified
by automated Chromium checks. Native Chrome folder access remains deferred (#117).
Window capture is recommended. OBS-specific sign-off is no longer required;
future OBS Browser Source deprecation is separate and unverified support is not
claimed. No new external service or dependency is introduced.

## Compatibility and recovery

Retain original editable ZIP backups. Native v1/v2/v3 and portable-authoring v1
remain importable; custom backgrounds use the separately approved guarded native
v4/authoring v2 formats. Untouched older files retain their generation. Older
editors reject unsupported new formats rather than discard backgrounds. See
[import compatibility](../import-compatibility.md).

Extract complete playback ZIPs and test actual media on the delivery machine.
Browser recovery drafts are not backups. Keep stable and beta origins separate;
moving between origins requires editable ZIP export/import. App promotion does
not publish the companion website or alter browser storage automatically.
