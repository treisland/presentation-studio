# 0.20.0-alpha.1 — Media authoring and management

Development preview for maintainer local testing, milestone 28 / #289.

- Project media: budget, search/type filters, original previews, assignment locations,
  display names, missing/unsupported states and slide narration indicators.
- Local microphone recording: device selection, level feedback, elapsed time,
  ten-minute/portable-byte limits, preview, retake/discard and explicit Use take.
- Immediate canvas-adjacent narration strip with ready/record/review states, measured
  waveform/seek preview, device menu and original-target protection across slide changes.
- Reviewed one/all-current-use replacement, Undo, browser-recovery lookup, file/folder
  candidate matching and exact-original restoration where a digest exists.
- Original individual/bulk downloads with collision-safe filenames and a manifest;
  missing originals require acknowledgement for incomplete media downloads.
- Current/all-local project scopes, unused/recovery review, bulk selection and safe
  current-project deletion with explicit recovery-history clearing, backups and atomic
  rollback/concurrent-edit protection. Exact-byte duplicate consolidation retains Undo;
  all-local browsing and reuse leave source projects unchanged.
- Guarded native v6 retains library metadata and originals through editable packs,
  history and browser recovery. Existing v1–v5 imports remain supported. Older Studio
  builds reject v6. Playback omits the author catalog and retained inactive originals.

No external recording service, transcoding, audience download permission, backend,
timeline editor, transcription, take-history manager or companion deployment.

Real microphone/browser/codec, keyboard/screen-reader, dark/narrow and offline
delivery acceptance remains pending maintainer testing. Synthetic browser tests do
not establish actual audible output. See [the guide and contract](../media-authoring.md).

This preparation disables publication while the maintainer tests the GitHub branch.
