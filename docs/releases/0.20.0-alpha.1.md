# Presentation Studio 0.20.0-alpha.1

This alpha introduces local media authoring and management, milestone 28 / #289.
The maintainer confirmed local manual testing passed and authorized this release
on 2026-11-16. It is a prerelease for early use and feedback.

- Record slide narration locally with microphone/device/level controls, bounded
  capture, preview, retake/discard and explicit Use take. Canvas-adjacent controls
  provide measured waveform/seek previews and protect the original target slide.
  Final encoder data drains before microphone release; incomplete takes cannot
  replace narration and remain downloadable.
- Find project originals by type, search, usage, health and size. Preview, rename,
  locate assignments, repair missing media and review shared replacements with Undo.
  Download individual originals or media ZIPs with collision-safe manifests.
- Manage unused/recovery media, bulk assignments and exact-byte duplicates.
  Permanent deletion uses one consequence-labeled review, protects current/Trash
  assignments and handles saved-project/assets atomically. Recovery cleanup
  explicitly clears history. Backup, abort and concurrent-edit protections remain.
- Browse All local projects in this browser profile, preview/download owned files
  and copy originals into the current project. Other projects remain unchanged;
  there is no disk scan or cross-project deletion.
- See narration presence, duration, inactive/missing status and effective slide
  advancement beside the canvas and on thumbnails. Project defaults in Audio
  (after Background), slide overrides and linked silent-slide timing support
  manual, narration-ended and timed advancement. New blank projects start Manual;
  existing timing stays preserved until explicitly reset. Continue without audio
  releases narration-driven holds while intentionally Manual slides stay manual.
- Project media shows measured elapsed/total time before Play, with local seeking,
  mute and volume. Older missing-duration originals are measured in the background
  without playback or re-encoding. Current/all-local previews share the controls.

## Compatibility and recovery

Guarded native v6 retains catalog metadata and originals through editable packs,
history and browser recovery. Existing native v1–v5 projects remain supported;
older Studio builds reject unsupported media/policy metadata instead of stripping
it. Playback/booth exports omit inactive/recovery originals and retain exported
slide policies. Project/slide IDs and original bytes are preserved. Keep editable
ZIP backups; browser recovery is not a backup. Existing exported HTML retains its
embedded runtime: rebuild exports with this version to obtain the fixes.

## Validation and limitations

Local automated validation passed 568 tests and packaging; see the
[validation record](0.20.0-alpha.1-validation.md) for protected CI and maintainer
acceptance evidence. Maintainer manual acceptance does not establish a new
cross-browser/OS/codec or screen-reader certification. Broader real-device,
accessibility and multi-minute recording coverage remains documented there.
Synthetic browser tests do not establish actual audible output.

No external recording service, backend, transcoding, timeline editor,
transcription or take-history manager is added. This release authorizes the
canonical GitHub prerelease and its four artifacts only; no companion, Pages
or container publication is included. See [Project media](../media-authoring.md),
[import compatibility](../import-compatibility.md) and [known issues](../known-issues.md).
