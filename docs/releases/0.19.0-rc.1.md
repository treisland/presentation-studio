# Presentation Studio 0.19.0-rc.1

This release candidate promotes the maintainer-tested 0.19 beta runtime without
code changes and explicitly authorizes its deployment to beta.pres-studio.com.
It prepares the same runtime for the approved production 0.19.0 release (#282).

The release includes native editable column/bar/line/donut charts, named color
pickers, inline data controls, portable AI chart authoring and refreshed agent
instructions. It retains the accepted menu/start screen, recovery, audio and
portable export workflows. See [the beta feature notes](0.19.0-beta.1.md) and
[validation and authority](0.19.0-rc.1-validation.md).

Known [holding-screen limitation #241](../known-issues.md) remains: explicitly
choose Built-in design if a saved holding slide was hidden/deleted. No fix is
claimed. Platform/screen-reader/codec support is unchanged. Window capture is
recommended; unverified OBS Browser Source support is not claimed.

Keep editable ZIP backups; browser recovery is not a backup. Export/import an
editable ZIP when moving between stable and beta origins. Import an old editable
export into this version and export again to receive the updated bundled runtime.
Preserve original media and extract complete playback ZIPs before delivery.
See [compatibility](../import-compatibility.md) and [recovery](../local-workspaces.md).

Only beta Pages hosting is authorized by this candidate's distribution plan.
Production uses its separate 0.19.0 plan. No Docker aliases, DNS changes or
companion-site deployment are included.
