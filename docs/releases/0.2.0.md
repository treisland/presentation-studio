## Backups, recovery and opening packages

Download and extract complete packages before opening their HTML. Keep an editable ZIP containing all media before clearing browser data, changing profiles or moving computers. Browser-local drafts are profile-specific and are not portable backups.

Use Project → Export → Verify backup ZIP to inspect a backup without replacing the current project. Verification establishes archive/data integrity, not video decodability or rendering. Prove restoration by importing the editable ZIP in a separate browser profile and checking media and content offline. A playback export is for delivery, not a substitute for an editable backup.

Use undo for recent edits and Project settings recovery controls for trash/checkpoints; keep the current project backed up before restoring or resetting. If a draft cannot be saved or an asset is missing, preserve the original files/profile and export a complete editable backup where possible before troubleshooting.
