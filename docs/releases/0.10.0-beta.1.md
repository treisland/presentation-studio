# Presentation Studio 0.10.0-beta.1

Maintainer-approved beta for application identity, import compatibility and Docker/Pages distribution. This is a prerelease; stable 0.7.0 and previous release tags remain unchanged.

- See the loaded app version in the Presentations footer, editor status bar and Project → About. About reports channel, build and supported imports; copy diagnostics without presentation content or local paths. Works offline and keeps version controls out of audience playback.
- Document format-based compatibility: native editable project v2, existing legacy v1, portable AI authoring v1 and component library v1 remain supported. No format support is retired.
- Start a fresh source checkout with `docker compose up --build -d`, without host Node/npm or manual `site/` generation. Source builds are clearly development builds. Docker runtime is nonroot/read-only compatible, loopback-bound by default, with a health check and pinned base stripped of unused package managers.
- Keep release distribution separate: the verified-prebuilt target serves canonical release HTML bytes. Explicit GHCR/Pages promotion verifies authorization, tag/checks/workflow, all four asset digests and embedded identity. Stable/prerelease channels are separated and downgrade/conflict guards remain enforced.
- Review deployments use a bounded, exact-hash static archive transferred through a reviewed beta-repository commit. CI stays read-only and never executes downloaded PR code. Namecheap DNS, origin migration and recovery guidance are included.

## Run and preserve your work

Download the full package ZIP and extract it, then open `presentation-studio.html` or the blank entry point. Files remain portable; no application server or database is required. Keep complete editable ZIP backups, especially before changing browser profiles, hostname/protocol/port or application versions. Browser recovery is not a portable backup.

After downstream promotion succeeds, the beta site is [beta.pres-studio.com](https://beta.pres-studio.com/) and the versioned image is `ghcr.io/treisland/presentation-studio:0.10.0-beta.1`. Registry/website publication are separately verified operations, not implied by canonical download publication. Prefer the verified OCI digest for pinned installations. Docker serves the app; it does not store or synchronize presentations. Source-checkout instructions and reverse-proxy guidance are in [deployment](../deployment.md).

## Acceptance and limitations

The maintainer confirmed the beta URL/domain and Docker-only fix, granted sign-off and explicitly confirmed all listed manual beta gates. See the [validation record](0.10.0-beta.1-validation.md). Exact manual OS/browser/screen-reader/OBS versions and recording URLs were not supplied; no broader environment certification is implied.

Linux AMD64 is the tested image baseline; ARM64 certification remains deferred. Native folder access, npm publication, server storage, accounts, collaboration and grouping follow-ups are not introduced here. Keep existing accessibility/OBS evidence follow-ups visible. Do not roll back code against newer browser data without compatibility review. Future RC/stable promotion requires separate authorization.
