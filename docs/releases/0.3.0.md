# v0.3.0 — Canvas, media and editor panels

Stable 0.3.0 promotes the published, maintainer-tested release candidate without runtime, dependency or project-format changes. The maintainer confirmed the RC passed and authorized an official release.

## Included improvements

- Responsive canvas workspace with collapsible/resizable Slides and Inspector panels, Fit/manual zoom and panning.
- Additive media preserves content by default; explicit replacement names/previews its target. Background media stays behind text.
- Text, Rectangle, Circle and Callout blocks with visible Move/Resize controls, snapping, alignment, layers, keyboard placement and atomic Undo.
- Media Grid uploads, presets/custom dimensions, fit/crop, swaps, overflow retention, divider resizing and locks.
- Inspector Content/Arrange/Style tabs, pinned selection actions, directional reveal rails and keyboard thumbnail actions. Grid object-list selection synchronizes the removal target; slide duplication retains Grid media.
- Named keyboard Media Focus action and versioned local editing operations with revision checks, shared locks and recovery checkpoints.

Existing IDs, recovery assets and offline editable/playback exports remain supported. No external service or project-format migration is introduced.

## Support and evidence

Protected Chromium workflows validate Windows/Linux authoring, keyboard navigation, locks/Undo, media focus, legacy imports and offline editable/playback reopening. The maintainer reported functional, actual delivery-video/OBS and new-panel screen-reader passes, then confirmed testing of the published RC. See [the evidence record](0.3.0-evidence.md).

## Backups and recovery

Extract complete packages before opening their HTML. Keep a full editable ZIP with all media before clearing browser data, changing profiles or moving computers; local drafts are profile-specific. Playback exports are for delivery, not editable backups.

Use Project → Export → Verify backup ZIP for archive/data integrity, then prove restoration by importing the editable ZIP into a clean profile and checking media offline. Verification does not establish codec support. Use Undo for recent edits and recovery controls for trash/checkpoints; preserve original assets and a complete backup before reset or restoration.
