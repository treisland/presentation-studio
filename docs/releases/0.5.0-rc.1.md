# v0.5.0-rc.1 — Layout collections and examples

This candidate adds reusable theme-independent compositions, examples and optional editor guidance within the existing 16:9 slide format. Stable 0.4.0 remains the stable release while this candidate is reviewed.

## Included improvements

- Twenty-one collection compositions: Portfolio (5), Comic (4), Editorial/Newspaper/Blog (5), Newsletter (4) and Flyer (3). The sampler now covers thirty core/collection layouts including Blank.
- Three complete starter/demo pairs for Portfolio, Comic and Editorial, plus lightweight Newsletter/Flyer starters. Original neutral artwork, descriptions and credits work offline.
- Start from an example gallery from Project, Recent presentations and New presentation, with purpose/image filters, complete slide previews and readable preview text/descriptions. Preview is view-only; Use creates a fresh project after save-before-switch succeeds.
- Explicit optional Portfolio, Comic and Editorial walkthroughs with Skip/Close/Replay, keyboard/focus and reduced-motion handling. Cues stay outside project/history/export state and use selected-cell media controls.
- Previewed retained-content layout mapping preserves complete text/tables, media identities, locks, Undo and unmatched content; overflow is flagged without automatic tiny text. Custom Editorial mastheads map separately from article content.
- Repeated Reset restores the example copy's own baseline. Fresh asset paths copied from immutable bundled artwork prevent imported filename collisions from replacing library images or overwriting another draft's assets. Comic preview captions have reserved space.

No schema migration, external service, runtime dependency change or new canvas format is introduced. Themes/swatches and existing design controls continue to apply. See [the example guide](../examples.md) and [collection guide](../layout-collections.md).

## Scope and support

All collections produce **16:9 slides**. Newsletter is not email-client HTML or sending; Flyer is not portrait/print-ready output, bleed, CMYK or PDF; Editorial is not a scrolling website or publishing service. Long copy and retained unmatched material may need rearrangement or another slide. Review placeholder contacts/dates, credits and image descriptions before sharing. AI and MCP remain separate milestones.

The maintainer reported all supplied manual reviews passed and separately reported latest OBS, Chrome, Edge and Firefox passed. Protected automated coverage uses Chromium on Windows/Linux. Exact numeric manual OS/browser/screen-reader/OBS versions, capture method and scaling remain unspecified. Automated tests do not independently prove manual OBS/accessibility results, and detailed environment follow-ups #7/#9 remain open. Late review corrections have focused automated coverage without a claimed additional manual pass. See [the evidence record](0.5.0-evidence.md).
