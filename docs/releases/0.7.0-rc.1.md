# 0.7.0-rc.1 — Portable AI presentations

Release candidate for the combined authoring improvements from 0.6.0-beta.1 and the approved portable AI workflow. This is a prerelease; stable 0.7.0 requires acceptance of the published RC downloads and a separate release plan. The previously published 0.6.0-beta.1 remains unchanged. See the [validation record](0.7.0-rc.1-validation.md).

## Included

- Provider-independent AI instruction pack with a shared schema, capability catalog and neutral examples. Generate presentation JSON using an LLM of your choice without connecting a provider, supplying API keys or installing MCP.
- Project → AI presentations: import an individual JSON/editable ZIP or paste JSON, validate, inspect inert previews and repair malformed or unsupported input before changing the active project.
- Auto/explicit native-element layouts, per-slide review overrides, measured fit warnings, readable text defaults and undoable post-import reflow. Authoring v1 remains compatible.
- Editable text, lists, Tables, Code/Commands and native Quote, Metric, Callout, Step and Arrow elements. Existing Library, reusable components, names, Layers, visibility, template positioning, Inspector, locks and Undo behavior from the beta are retained.
- Ordinary editable ZIP downloads preserve content, media and recovery history. Browser recovery remains separate. Existing editable formats, IDs, legacy import and offline playback remain supported.

## Downloads and upgrade

The versioned ZIP contains presentation-studio.html, presentation-studio-blank.html, bundled resources, AI instructions and examples/documentation. Extract the full ZIP before opening an HTML app. The two HTML apps and studio-demo-editable.zip are also available separately.

Before upgrading important projects, export an editable ZIP from the existing app. Import it into this candidate and verify content, media, history and playback. Keep that backup: browser recovery is tied to its profile/origin and can disappear when browser data is cleared. Export component libraries separately for transfer. Older editors may omit newer optional authoring metadata when resaving; use this version for continued editing.

In the candidate choose Project → AI presentations → Create / import. Download the instruction pack, generate a complete JSON document, validate and review it, then open and edit. Export / recovery → Download editable ZIP creates a portable copy. To use external edits, import the updated file and review it again. Studio does not link to or overwrite the source file through a native file handle.

## Scope and known limitations

- Live folder browsing/reconnect, linked saves/reloads, native save pickers and folder snapshots are deferred outside 0.7.0. The native Chrome picker rejection remains an [open investigation](https://github.com/treisland/presentation-studio/issues/117), not a claimed fix. Existing user files, browser projects and old handle preferences are retained. Diagnostic tools do not ship in the product archive.
- Auto layout is deterministic and uses documented native compositions; it does not ask an LLM to choose a layout or reproduce every template. Inspect fit, reading order and placeholders; warnings are not a guarantee of readable output.
- Validation checks structure and supported fields, not factual accuracy, source quality, licensing or LLM output quality. Add appropriately licensed media yourself. No automatic network requests, uploads or provider integrations are introduced. Displayed commands never execute.
- One native Code block per slide; additional snippets use an editable fallback with a substitution notice. Groups remain one level and arrows are free annotations, without attached/routed connectors.
- Authoring JSON is an input format, not the lossless editing format. Use complete editable ZIPs for projects containing media. Import limits remain 100 MB input, 20 MB native JSON, 2 MB authoring JSON, 1,000 ZIP entries and 200 MB streamed expansion.
- Exact manual OS/browser/screen-reader/OBS versions and retained recording URLs were not supplied. Automated Windows/Linux validation is distinct from manual compatibility evidence; do not infer a certified version matrix.
