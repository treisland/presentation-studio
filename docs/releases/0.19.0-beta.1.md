# Presentation Studio 0.19.0-beta.1

The maintainer-accepted Charts & Graphs milestone adds native editable charts and
matching portable AI authoring support to the existing editor and start screen.

- Insert column, horizontal bar, line and donut charts from the Library, with
  real data previews, spreadsheet paste and a staged Data/Style editor.
- Pick colors for named series or donut categories, or follow the presentation
  theme. Add categories/series inline and remove any targeted item while keeping
  the other values and colors aligned. Apply/Cancel, focus and Undo stay predictable.
- Reopened editable HTML supports Cancel, Apply, Enter and Escape without a
  focus-restoration loop or a cleared editing session.
- Portable AI authoring v1/v2 supports native chart blocks and chart/auto layouts,
  validated data, editable import/reflow and a complete four-chart example.
  Refreshed agent instructions/catalogs distinguish native support from manual
  Library steps; no personal components, media or services are accessed automatically.
- Preserve project/object identities, recovery, locks, component transfer and
  offline editable/playback/booth exports. Charts do not require a native format
  generation bump, new dependency or external service.

Download a fresh AI instruction pack for the new schema/catalog/examples. Existing
standalone exported HTML keeps its bundled app runtime: import its editable ZIP
into this build and export again to receive the fixes.

See [Charts & Graphs](../charts-and-graphs.md), [AI instructions](../ai/AUTHORING.md)
and [release validation and authority](0.19.0-beta.1-validation.md).

Known [holding-screen cancellation issue #241](../known-issues.md) remains separate.
Screen-reader/platform/codec limitations and public screenshot review retain
their documented scope. This authorization covers the canonical beta release;
stable publication, downstream hosting/Docker aliases, companion deployment and
DNS changes require their separate authority.
