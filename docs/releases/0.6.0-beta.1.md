# 0.6.0-beta.1 — Authoring customization beta

Maintainer-approved prerelease of the merged 0.6.0 authoring work. This is a beta, not the stable 0.6.0 release. Manual release gates were confirmed by the maintainer on 2026-11-09; see the [validation record](0.6.0-beta.1-validation.md).

## Included

- Contextual toolbar and selection-aware Inspector, with explicit slide settings, structured widget/code/table editing and an optional Inspector text editor.
- Searchable Library with editable Callout, Quote, Metric and Step widgets, media insertion, Tables and shared Code/Commands with optional labels/variants.
- Movable/resizable/removable free blocks and explicit conversion for older table/code content; template heading deletion and independent duplication preserve slide identity.
- One-level groups, independent reusable presets, local deletion recovery and portable library export/import with required media.
- Unified element visibility, editor-only hidden-element inspection and presentation defaults/per-slide header, footer, logo, number and decoration visibility.
- Automatic type-numbered element names, custom overrides and Layers search.
- Opt-in template section/card/text positioning with measured placeholders and reset without reverting edited content.
- Step sequences with automatic numbers/manual overrides, and free Arrow/Pointer annotations with endpoint handles, snapping, styling, labels and descriptions.
- Editable backup, recovery, offline playback and standalone booth support for the new authoring content.

## Downloads and use

Use the full versioned ZIP for the HTML apps, bundled resources, original examples and documentation. Extract all files before opening presentation-studio.html or presentation-studio-blank.html. The two HTML files are also available separately; studio-demo-editable.zip is an editable example.

Keep an external editable ZIP backup before upgrading important projects. Commands are displayed/copied only and are never executed. Library storage is local to the browser profile; export its JSON for backup or transfer. Inserted component copies are independent.

## Beta scope and limitations

- Manual keyboard, screen-reader, real delivery video/OBS, clean-profile editable restore, offline playback and legacy import checks were confirmed passed. Exact OS/browser/screen-reader/OBS versions were not supplied, so this beta does not certify a particular manual environment/version matrix. Automated Windows/Linux validation is separate evidence.
- Existing projects are unchanged on open. Current editable exports preserve optional authoring metadata. Older editors may display fallback content but do not provide the new controls and can drop metadata when resaving; exact backward editing is not guaranteed.
- Groups have one level; linked instances, attached/routed connectors, cloud collaboration and interactive/timed widgets are excluded. Arrows are free annotations.
- Customize position is explicit for ordinary template content. Structured grids/media/tables retain their specialized controls. Ungroup before resetting an individual template position or editing an arrow endpoint. Applying a new layout with retained content keeps customized blocks independent and removes the old reset link; Undo restores it. Review overflow and reading order after detaching nested content.
- One code block per slide. Optional variants are display/copy content; empty variants are omitted. Library limits remain 40 presets/16 MB import, subject to browser storage quota.
