# 0.6.0-beta.1 — Blocks, Widgets and Reusable Components review

Beta review build, not authorized for publication until maintainer manual testing passes. See [scope and manual acceptance](../blocks-components.md).

Use Add / Library above the canvas to search Text, Shapes, Media, Widgets or Library. Callout, Quote and Metric fields can be edited in Inspector Content or directly on the canvas. The formatting toolbar shares existing text style, size, bold/italic and alignment controls; object appearance, alignment, ordering, locking and grouping are adjacent. Detailed controls remain in the Inspector. Mixed object colors are identified; explicit colors remain fixed while inherited colors follow the theme.

Select several free blocks or floating media in Layers, then Group. Movement/resizing of a member moves/scales its group; group controls operate atomically and respect locked children. One group level is supported. Use Ungroup to edit objects independently. Other structured content remains editable with its existing tools; convert it to free blocks before grouping.

Name a selected block/group and Save selection to library. Library copies are independent, use fresh object identities and include required media at fresh asset paths. Presets can be renamed, duplicated or deleted; Restore last deleted preset recovers up to ten recent deletions. Export a library JSON backup before clearing browser data. Libraries are local to the browser profile and do not automatically travel with presentation ZIPs; inserted copies do. Import merges libraries after validation and does not replace the active project. Maximum 40 presets, 16 MB import; browser storage quota can be smaller and failures are reported.

Ordinary safe slide content and optional design metadata preserve readable playback and existing schema-v2 project compatibility. Older editors can render the content but may drop grouping metadata when resaving. No linked components, timers, cloud accounts or collaboration. Retain external editable backups and test offline restoration before upgrading important presentations.

Manual review required: laptop/zoom, dark/light themes, keyboard and screen reader, actual video/OBS where claimed, legacy imports, grouped image portability, clean-profile library transfer, saved project restoration and offline playback. No new manual pass is claimed from automated tests.
