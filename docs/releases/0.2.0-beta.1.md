# v0.2.0-beta.1 — Release preparation

This beta freezes the 0.2.0 feature scope. No new canvas or AI features are included; those belong to later milestones.

The release scope includes presentation readiness, media regression coverage, isolated backup verification, keyboard navigation and accessible control names. Project formats and offline editable/playback workflows remain unchanged.

## Evidence and publication gate

See [the release evidence record](0.2.0-evidence.md). The maintainer reported the supplied test plan and OBS checklist passing without defects. Exact environment details and explicit remaining recovery/legacy results are outstanding. These reports do not establish broad browser, codec or screen-reader support.

The maintainer explicitly granted beta sign-off after reviewing the outstanding evidence requirements. Publication is authorized with these documented beta limitations: exact environment/build metadata and explicit legacy/full-recovery manual results remain unspecified. The sign-off accepts these gaps for beta; it does not claim missing tests were performed. Release automation still requires protected CI and verified artifacts. See the evidence record for the acceptance and exceptions.
