# Presentation Studio 0.18.0-beta.1

The maintainer-accepted editor menu bar and start-screen milestones are now
prepared together for beta. This prerelease retains existing project formats,
identities, recovery media and offline editable/playback/booth reopening.

- A start screen offers Recent projects, Open project ZIP/JSON, an empty canvas,
  existing templates/starters and an editable example.
- Browser-local startup preferences show the screen, resume the last project,
  create a blank presentation or prompt for file opening. The OS picker requires
  a click. Exported projects still open directly.
- Pending recovery does not block deliberate start-screen choices. Its content,
  history and media remain saved; same-ID imports preserve a previous local
  version. Recovery still takes precedence over automatic startup.
- File/Edit/View/Insert/Format/Arrange/Slide/Help menus share existing handlers,
  selection guards and Inspector destinations, with keyboard and narrow layouts.
- Help opens the published documentation and gallery. Automatic edge banners
  are removed; on-demand Check readiness retains overflow findings.
- Keyboard-help dismissal and shortcuts stay within that dialog, preserving
  the editor, preview and Undo state.

See [start-screen behavior](../start-screen.md), [editor commands](../editor-menu.md)
and [validation and authority](0.18.0-beta.1-validation.md).

Known [holding-screen cancellation issue #241](../known-issues.md) remains accepted
for a later patch. Historical independent evidence and public screenshot review
remain separate. This plan authorizes canonical beta publication; stable release,
hosted distribution, companion deployment and DNS changes are not included.
