# Presentation Studio 0.14.0-beta.1

This beta includes the completed canvas movement and editor usability milestone (#172–#177) and the initial media placement fix (#184).

- Consistent screen-space movement and resize grips, including visible canvas edges.
- Shared single/group movement snapping, Shift axis locking, Alt bypass, a four-CSS-pixel move threshold and reliable cancellation.
- Explicit template free-positioning/reset actions and lock guidance.
- Clear selection/group/text context, accurate keyboard movement units and completed-move announcements.
- Inspector color drafts, caret and focus preserved across resize.
- Initial Left, Right and Background media drops/uploads honor the chosen placement. Existing rotated media frames, metadata and locks survive primary swaps with one-step Undo.

The profiling harness records a reproducible baseline; it does not promise a performance SLA or remove the documented post-gesture refresh costs. No new dependency or project format is introduced. Keep original editable ZIP backups. See the [canvas guide](../canvas-manipulation.md) and [validation record](0.14.0-beta.1-validation.md).

Distribution targets beta Pages and versioned/beta GHCR. External links require connectivity; downloaded authoring and playback remain offline-capable. Existing support limitations from [0.13.0-beta.1](0.13.0-beta.1.md) continue to apply.
