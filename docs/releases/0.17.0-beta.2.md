# Presentation Studio 0.17.0-beta.2

This beta brings the current dev UI to the released application: refined audio layout and explicit transport controls, consolidated Background settings, and full-window editor sizing. It includes PR #262, which merged after beta.1's immutable source was frozen. No audio format generation, dependency or stable-channel change is introduced.

Retain complete editable backups and unzip whole playback packages before opening them. Guarded native audio v5, v1–v4 imports and audio-free compatibility remain as documented in [Audio](../audio.md). Known [#241](https://github.com/treisland/presentation-studio/issues/241) remains open with the Built-in holding-design workaround.

The maintainer authorized beta.2 from current dev and deployment to beta.pres-studio.com. Stable pres-studio.com and latest v0.16.0 remain unchanged. Beta.1's tag and assets are retained. See [validation](0.17.0-beta.2-validation.md). Publication and beta hosting are separate verified steps; the hostname must report beta.2's exact immutable source after deployment.
