# v0.5.1 — Editor usability corrections

This patch builds on stable 0.5.0 with the maintainer-reviewed text-type and New presentation fixes from #93/#94, integrated through #95/#96.

- Inspector Content exposes existing Heading 1–3 and Paragraph conversion. Inline formatting, selection, layout identity, primary-title synchronization, locks and one-step Undo are preserved. Unsupported structured content cannot be converted; no div/group or new project schema is introduced.
- A converted Heading 3 title stays in its title slot when applying another layout with retained content, including Undo and editable reopening.
- New presentation keeps Blank and Import alongside one Start from an example entry. The dedicated gallery retains all five collections and the generic Studio demo, including immutable previews from the blank build. Choosing an example continues naming/theme setup before creating a fresh project; cancellation, save-before-switch, reset baselines and offline exports remain guarded.

No dependency, saved-project format or canvas-format change is introduced. Existing projects retain their IDs and assets. All collections remain 16:9 slides; Newsletter is not email HTML and Flyer is not print-ready output. Existing 0.5.0 support limitations remain applicable.
