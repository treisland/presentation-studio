# v0.3.0-rc.1 — Canvas, media and editor panels

This release candidate freezes the maintainer-tested 0.3.0 feature scope. Test the published candidate artifacts before stable 0.3.0 sign-off; local development testing does not establish that the as-yet-unpublished package passed.

## Included improvements

- Responsive canvas workspace with collapsible, resizable Slides/Inspector panels, Fit/manual zoom and panning.
- Additive media placement preserves content by default; explicit replacement previews and names its target. Background media stays behind text.
- Text, Rectangle, Circle and Callout blocks with Move/Resize controls, snapping, alignment, layers, keyboard placement and atomic Undo. Circle handles remain visible outside the clipped shape.
- Media Grid cells with uploads, presets/custom dimensions, fit/crop, swaps, overflow retention, divider resizing and locks.
- Inspector Content/Arrange/Style tabs, pinned selection actions, directional reveal rails and keyboard thumbnail actions. Grid object-list selection keeps the displayed cell and removal target synchronized; duplicating slides retains Grid media.
- Accessible Media Focus action on keyboard focus in Preview/presentation; versioned local editing operations with revision checks, shared locks and recovery checkpoints.

No external service, major dependency or project-format migration is introduced. Existing project IDs, recovery assets and offline editable/playback exports remain supported. This release preparation changes metadata/documentation only relative to merged feature commit ffbd437.

## Backups and recovery

Extract complete packages before opening their HTML. Keep a full editable ZIP with media before clearing browser data, changing profiles or moving computers; browser-local drafts are profile-specific. Playback exports are for delivery and are not editable backups.

Use Project → Export → Verify backup ZIP for archive/data integrity, then import the editable ZIP into a clean profile and check media offline. Verification does not establish codec support. Use Undo for recent edits and recovery controls for trash/checkpoints; preserve original assets and a complete backup before resets.
