# Presentation Studio 0.17.0-beta.1

Audio & narrated playback beta, authorized by the maintainer on 2026-11-13 (America/Denver). Publication still requires the reviewed release plan on main, exact-commit platform validation and successful immutable-tag validation/artifact verification.

## Audio authoring and playback

Attach local per-slide or presentation-wide narration and independent looping background music. Preview explicitly, retain original assets, and export complete editable, playback and standalone booth ZIPs. Unzip the entire package before opening it.

Audience playback starts only after an explicit gesture. Session mute, volume, seek and restart preserve authored defaults. Narration-end advancement and padding take precedence over slide/video timers; private Presenter previews stay silent. Pause, blackout, Media Focus and reconnect invalidate stale callbacks and ownership. Booth audio fields retain native keyboard controls.

## Compatibility and limitations

Audio-bearing native packs use the maintainer-approved guarded v5 format. Native v1–v4 imports and existing audio-free export formats remain supported. Older editors cannot read v5; keep original editable backups. Public playback omits inactive narration/private history while editable packages preserve original media. Codec support depends on the browser; no recording, speech synthesis, automatic music ducking or cross-origin ownership guarantee is added. See [audio guidance](../audio.md).

Known [#241](https://github.com/treisland/presentation-studio/issues/241) remains open: after cancelling holding-screen settings with an unavailable custom slide, explicitly select Built-in design before showing the holding screen. No fix is claimed.

Use ordinary window capture. OBS Browser Source evidence is not required. Maintainer-reported acceptance and automated evidence are recorded in [validation](0.17.0-beta.1-validation.md); independent evidence issues remain distinct. This is a prerelease, not stable/latest promotion. Companion deployment and downstream Pages/GHCR promotion are outside this release plan.
