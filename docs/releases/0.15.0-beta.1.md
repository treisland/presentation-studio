# Presentation Studio 0.15.0-beta.1

This beta combines the v0.15.0 Inspector and contextual-action milestone with the accepted text Inspector simplification.

- Independently collapsible Inspector sections retain session preferences and reveal the existing editor from shortcuts.
- Text editing has one disclosure, directly accessible fields, short formatting guidance and a shared content scroller for notes/help.
- Selected-media Inspector owns placement, sizing/crop/shape, captions/alternative text, playback/posters and guarded restore. The competing Media Manager entry point is retired after the documented parity port.
- Library cards and placed objects share contextual actions through right-click, visible ellipsis and Shift+F10/Menu key, retaining existing selection, locks, Undo and native text-entry menus.

No format, project IDs, dependencies or external services change. Keep original editable ZIP backups. See [Inspector navigation](../inspector-navigation.md), [media behavior](../media-inspector.md) and [context menus](../context-menus.md).

Prepared for beta Pages and versioned/beta GHCR only. Publication awaits protected PR/main/tag/artifact gates with maintainer manual acceptance recorded. Existing support limitations remain; automated Chromium does not establish additional browser/OS or real OBS/screen-reader support.
